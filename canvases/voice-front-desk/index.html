§ 03Supported today9 modules · 38 features

Everything this canvas already does.

The inventory below is what ships before we change a line. It is a floor, not a ceiling: the features your company needs are defined in the audit and built on top.

  1. M-01

    Channels

    One agent, reachable the way people already reach you.

    • Voice agent in production, with transfer to a person
    • Email agent end to end: OAuth mailbox, tool loop, verification by link
    • WhatsApp text agent with a deterministic redirect guardrail
    • Same behaviour and knowledge across channels
  2. M-02

    Agent behaviour

    Control without prompt engineering.

    • Natural-language rules with priority and channel scope
    • Structured advisor rules evaluated by the booking engine
    • Six-section prompt builder with variables, diff and copy across channels
    • Push and pull of prompts per channel
    • Live editor for tool descriptions and parameters
  3. M-03

    Human handover

    A person is always one transfer away.

    • Transfer number, conference or SIP
    • Conditions for when to transfer
    • Server-side blocking of services the agent must not handle
  4. M-04

    Booking tools

    Real actions on a real calendar.

    • Multi-tenant MCP server with 15 tools
    • Identification, availability, book, move, cancel
    • One-time codes, email and information tools
    • Scheduling provider adapter: agenda, contacts, portal
    • Tools filtered by provider capability and agent profile
  5. M-05

    Knowledge

    What the business is, written once.

    • Registries for staff, services and customers
    • Knowledge base viewer with sync to the agent
    • Google Drive attachments for services and staff
    • Industry templates: vocabulary, base prompt, enabled tools
  6. M-06

    Conversations

    Nothing the agent says is lost.

    • Log with channel, outcome and period filters
    • Conversation detail with a dedicated widget per tool used
    • Transcripts persisted locally
    • Email threads inside the conversation
  7. M-07

    Caller context

    The agent knows who is calling before it speaks.

    • Caller identification before the conversation starts
    • Past and upcoming appointments injected as context
    • Resolved context stored per conversation
  8. M-08

    Platform and security

    Built to be operated for many customers.

    • Tenant-scoped data and encrypted provider secrets
    • Three roles with default-deny
    • One-time invitations and password reset
    • Access audit and rate limiting on sign-in
    • HMAC-verified webhooks and hashed agent keys
  9. M-09

    Metering and observability

    Know what runs, what fails and what it costs.

    • Usage events: call minutes, model tokens, processed emails
    • Idempotent daily rollups
    • Error logs by area and severity
    • Sync history with duration and delta
    • Plans and subscriptions per tenant; health status

§ 04Agents on this canvasOrdered data in · reliable work out

Structured enough for agents to be trusted.

Agents fail on ambiguity. A canvas removes it: typed data, explicit rules and a record of everything that happened, connected to the rest of your company.

  • Answers, books, reschedules, cancels

    Not a voicemail with better diction: the agent acts on the calendar through typed tools, and confirms what it did.

  • Follows rules you can read

    Behaviour is a list of sentences with priorities. When a conversation goes wrong, you create a rule from it.

  • Leaves a full record

    Summary, audio, transcript and every tool call are kept per conversation, reviewable by a person and usable by other agents.
